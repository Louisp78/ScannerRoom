## Content of `bathymetry.png`

8192×4096 greyscale equirectangular image (~5 km/pixel at the equator).
Each pixel is `band index × 20`: 0 = land, 1 = 0–200 m, 2 = 200–1,000 m,
then one band per 1,000 m up to 12 = more than 10,000 m. The globe shader
colours the bands and draws the isobaths and the coastline (0/1 boundary). The
data carries no styling.

It is generated by `playground/scripts/bake-bathymetry.py` (Python 3, numpy, Pillow),
which downloads the 12 layers and caches them in `playground/natural-earth/`:

```bash
python3 playground/scripts/bake-bathymetry.py
```

Light smoothing (~10 km) merges the very fragmented polygons of the abyssal plains,
which would otherwise look speckled; land stays sharp.

## Provenance and licence

[Natural Earth](https://www.naturalearthdata.com/), datasets `ne_10m_bathymetry_A_10000`
to `ne_10m_bathymetry_L_0` (1:10,000,000 scale), fetched from
[nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector/tree/master/geojson).
Public domain.

Beyond 8192 px the source brings no more detail (tested at 16384 px: only smoother
edges, 2 MB). Going further needs another source, for instance a continuous GEBCO
or ETOPO grid.
